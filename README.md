## Resumo das Práticas Realizadas

Nos desafios, apliquei conhecimentos essenciais de HTML e CSS, aprendendo a montar páginas com várias tags HTML e a estilizar, posicionar e organizar os elementos com CSS.

Enfrentei desafios na compreensão do propósito de certas tags e propriedades CSS, além de na organização correta dos componentes da página. Também utilizei conceitos importantes como classes, seletores, propriedades de estilo e a estruturação geral do layout.
